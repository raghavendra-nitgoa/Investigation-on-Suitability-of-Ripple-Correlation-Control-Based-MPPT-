# Discription
This work proposes a single-phase two-stage grid tied photovoltaic (PV) system employing ripple correlation control (RCC) for performing maximum power point tracking (MPPT) and one-cycle control (OCC) for operating the common ground transformerless inverter (CGI). 
# 📁 Included Scripts
INVERTER_CTRL.slx and MPPT_CTRL.slx- Inverter and MMPT control for obtaining the HIL and Hardware results presented in the manuscript.

OCC_DQ_RCC_PO_BOOST_COMMON_GROUND_UPM- MATLAB/SIMULINK file to obtain the all simualtion results presented in the manuscripts.

RCC_OCC_TS_TYPE1_HL.mdl- Power circuit model for obtain the HIL results using real time platform.

This repository contains all scripts required to reproduce the simulation and numerical results presented in the article.
